
## Data Flow

### Reading Data
```
Screen → ViewModel → Repository → DAO → Database
   ▲         ▲           ▲          ▲        │
   │         │           │          │        │
   │         │           │          ▼        ▼
   │         │           │      [Query]   [Table]
   │         │           │          │        │
   │         │           ◄──────────┴────────┘
   │         │                (Entity)
   │         ◄────────────────(Model)
   └──────────────────────(State)
```

### Writing Data
```
Screen → ViewModel → Repository → DAO → Database
                         │         │        │
                         │         │        ▼
                      [Model]   [Entity] [Insert]
```

## State Management

```
ViewModel
    │
    ├─► StateFlow<Data>  ────►  UI observes
    │                           and reacts
    ├─► MutableStateFlow       to changes
    │   (internal)
    │
    └─► Functions ◄────────────  UI triggers
        to update state          actions
```
